# Full cleaned Booking comparison

Both systems receive the same 3089 cleaned, unique, nonblank source reviews. The 500-review demo is a subset of this corpus, not extra independent data. `all_reviews.csv` retains one result per cleaned source review; part directories retain detailed independent opinions and traces. This inspected development corpus has no independent aspect sentiment labels: coverage and processing status are not accuracy. All model inputs retain source wording after the documented placeholder/whitespace cleanup.
