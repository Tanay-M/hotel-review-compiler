03 / INDIVIDUAL RESULTS

One review. One row.

All submitted reviews are available here. Table filters do not change the dashboard's totals.

Results for your IEEE-format report

Download report tables for per-review results, categories, issues, coverage, overall sentiment, and run metadata. Both aggregate scopes and every denominator are named.

Uploaded reviews have no independent gold labels, so accuracy, precision, recall and F1 are not measured here. The existing authored evaluation corpus tests declared language contracts. An independently annotated held-out dataset is needed for empirical accuracy claims.

The ZIP contains CSV and text files. The observed analysis time excludes upload, CSV decoding, reporting, and browser rendering; repeated timing experiments are needed for a performance study.
